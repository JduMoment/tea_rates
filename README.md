# 🍃 5 листов

> Один чай — разные чашки.

**[5listov.ru](https://5listov.ru)** — сайт отзывов на чай, где чай сравнивают **по магазинам**.
Один и тот же Те Гуань Инь или шу пуэр продают десятки магазинов, и в каждом он свой. По отзывам видно, где он лучше,
сколько стоит и какие ноты в нём слышат.

## Что умеет сайт

**Каталог и рейтинги**
- Чаи и магазины добавляют сами пользователи. Дубли магазинов отсекаются по адресу сайта.
- Рейтинги по категориям (зелёный, белый, жёлтый, улун, габа, красный, шу и шен пуэр, хэй ча, травяной), по магазинам
  и по чаям. Можно посмотреть, где лучше всего купить чай нужного вида.
- **Оценка с учётом опыта авторов.** Вес отзыва зависит от того, сколько разных чаёв автор уже оценил (от 0,2 до 1),
  а поправка на щедрость убирает разницу между теми, кто всем ставит «пятёрки», и строгими авторами. Благодаря этому
  магазин с десятком восторженных отзывов от новичков не обгонит проверенную чайную. Оценка дополнительно сглажена,
  поэтому цифры на сайте совпадают с порядком в рейтинге.

**Отзывы**
- Оценка в листьях, ноты вкуса на колесе ароматов, терпкость, шкалы настоя (тело, крепость, послевкусие), фото.
- Голоса «полезный отзыв» и сортировка по полезности.
- Под именем автора показан его опыт, например: «N чаёв · N видов · N магазинов».

**Вкус**
- Поиск по вкусу: на колесе ароматов выбираете ноты и получаете чаи, в которых их слышат.
- Личный вкусовой профиль по своим отзывам и подборка «Вам может понравиться».

**Цены**
- Цена за грамм и сортировка по ней.
- График истории цен в каждом магазине.
- Сравнение одного чая в двух магазинах.

**Заваривание и дневник**
- Чайный дневник: температура, объём, навеска, проливы, впечатления. Есть черновик записи и кнопка «Подставить, как
  обычно заваривают».
- Блок «Как заваривают этот чай» на странице чая: медианы по записям в дневниках, отдельно по тем, кому чай
  понравился. Пока записей мало, показываются типичные параметры для вида чая.
- Таймер проливов.
- Чайная полка со статусами «Хочу попробовать», «Есть дома», «Закончился», «Хочу повторить».

**Авторы**
- Публичная страница автора с отзывами и разбивкой опыта по видам чая. Дневник остаётся личным.
- Подписки на авторов и лента их отзывов.

**Прочее**
- Вход по почте и паролю или через Яндекс ID, восстановление пароля по почте.
- SEO: `sitemap.xml`, `robots.txt`, превью ссылок (Open Graph) с картинками, которые генерируются на сервере.
- Форма обратной связи, письма об ошибках на сайте, ночные бэкапы.

## Стек

| Часть    | Технологии                                                                 |
|----------|----------------------------------------------------------------------------|
| Бэкенд   | Python 3.12, FastAPI, SQLAlchemy 2 (async) + asyncpg, Pydantic 2, Alembic  |
| База     | PostgreSQL                                                                 |
| Фронт    | React 19, TypeScript, React Router 7, Vite, React Compiler                 |
| Картинки | Pillow: превью фото, Open Graph-картинки                                   |
| Тесты    | pytest + pytest-asyncio, vitest; линтер и форматтер ruff                   |
| Прод     | Docker Compose, Caddy (HTTPS через Let's Encrypt), один VPS                |

Фронт собирается в `front/dist` и отдаётся тем же FastAPI. Отдельного веб-сервера для статики нет, Caddy работает
только как HTTPS-прокси.

## Разработка

```bash
cp .env.example .env                                   # и заполнить
docker compose -f deploy/docker-compose.yml up -d      # Postgres, бэкенд с --reload, сборка фронта с --watch
poetry install                                          # зависимости на хосте — для тестов, миграций, линтера
alembic upgrade head                                    # схема БД
docker compose -f deploy/docker-compose.yml exec backend python -m back.seed --author <ваша почта>   # демо-данные
```

Сайт — http://localhost:8000, API — http://localhost:8000/docs.
Фронт собирает контейнер `frontend` (на хосте нужен Node 20+).

Все настройки описаны с комментариями в [`.env.example`](.env.example). Для локальной разработки достаточно
`POSTGRES_*`. Без SMTP письма пишутся в лог бэкенда, без `YANDEX_CLIENT_ID` вход через Яндекс просто отключён.

## Тесты

```bash
poetry run pytest                                               # бэкенд: отдельная база tea_rates_test, схема — миграциями
docker compose -f deploy/docker-compose.yml exec frontend npm test   # фронт: vitest
poetry run ruff check back && poetry run ruff format --check back
```

## Миграции

Схемой управляет Alembic (`back/migrations`). Поменяли модели — создайте миграцию:

```bash
alembic revision --autogenerate -m "что поменялось"
alembic upgrade head
```

Тест `test_migrations_match_models` упадёт, если модели и миграции разошлись.

## Структура

```
back/
├── main.py          # приложение FastAPI
├── routes.py        # все маршруты в одном месте
├── views/           # обработчики HTTP: каталог, отзывы, дневник, рейтинги, авторизация, отдача фронта
├── services/        # бизнес-логика: scoring (взвешенные оценки), rankings, recommendations,
│                    #   brewing, prices, shelf, social, photos, previews, seo, oauth…
├── models/          # модели SQLAlchemy
├── schemas/         # схемы Pydantic для API
├── enums/           # виды чая, ноты вкуса, сезоны, статусы полки
├── core/            # конфиг, БД, сессии, почта, хранилище файлов, логи
├── migrations/      # Alembic
├── fixtures/        # демо-каталог для back.seed
└── tests/
front/src/
├── pages/           # страницы: каталог, чай, магазин, рейтинги, дневник, профиль, автор
├── components/      # колесо вкусов, график цен, таймер, форма отзыва…
├── api/             # клиент API
└── auth/            # контекст авторизации
deploy/              # Dockerfile'ы, docker-compose для разработки и прода, Caddyfile, бэкапы
```
